# SceneKeeper Installation

## Install from ZIP

1. Quit After Effects, extract `SceneKeeper.zip`, and open the included `SceneKeeper` folder.
2. On **macOS**, double-click `install-macos.command`. If macOS asks, confirm that you want to open it. On **Windows**, double-click `install-windows.bat` and confirm.
3. The installer creates the CEP folders if needed, copies SceneKeeper to the correct location, and enables CEP extensions for CSXS 11.
4. Restart After Effects and choose **Window > Extensions (Legacy) > SceneKeeper**.

Keep the installer in the extracted `SceneKeeper` folder next to `CSXS`. macOS may show a security prompt the first time; right-click the file, choose **Open**, and confirm. If the `.command` file loses its executable flag, open Terminal, type `bash `, drag the file into Terminal, and press Enter.
