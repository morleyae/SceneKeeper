SceneKeeper Help

Basics
Save and insert

Select a layer in After Effects, then click Save a Selected Clip. Double-click a saved clip to insert it at the playhead; click once to select it.

Organize

Search clips, right-click an empty area to reorder clips or folders, open folders with a double-click, and right-click an item for more actions.

Missing footage

Open Missing Footage to find unavailable sources and relink them. Clips using the same source update together.

Quick actions
Quick delete

Hold Shift and click an item's actions/trash button to delete without the confirmation dialog. It moves to Recently Deleted; it is not permanently erased.

Undo

Use the Undo button to reverse the most recent SceneKeeper or After Effects action.

Recover and transfer

Use the trash button to restore or permanently delete items. The document button imports or exports library data.

Settings and support
Settings

Use the gear button to configure previews and clip-saving/insertion defaults.

License help / device change

Message morley.ae on Discord for support or to move a purchased key to a new device.
